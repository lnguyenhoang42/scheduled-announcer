# scheduled-announcer

A Don't Starve Together server-only mod that announces important events in your world. No cross-compatibility with DS or DSE.

The workshop page is friend-only because my Steam account is limited.

Yes, the icon is misspelled, but no one's gonna notice unless you're told about it.

You can find the config here:
https://github.com/lnguyenhoang42/scheduled-announcer/blob/main/modoverrides.lua

## Features

### Can be disabled via config if too cluttered

- Announces when a boss respawns.
- Announces when a boss spawns.
  - Some bosses have a limited-distance-only trigger, like Spider Queen and Treeguard, due to how many can spawn in a single session.
- Announces full moon, new moon, and lunar storms.
- Announces when rifts open/close and are opening/closing.
- Announces when a boss is killed, with kill counting.
  - The count can be capped at a number via config.
- Announces when a seasonal boss respawns (except the Goose).
- Announces hound and worm attacks.
- Announces when rain starts and ends.
- Announces cave nightmare phases and cycles.
